# Shopping Card colors — QoL Enhancements / ACNH 3.0.3

ABD Teal is the main suite's default. Optional Files contains five
alternatives: Bell Gold, Hotel Blue, Poki Red, Island and Island Inverted.

1. Fully close the game.
2. In Optional Files, open `Shopping Card`, then your chosen color folder.
3. Copy the enclosed `QoL Enhancements - Shopping Card` folder into your mods
   folder, replacing the existing module. Each color includes its configuration
   marker and layout; Core is still required.
4. Keep Core and Shopping Card enabled, then restart.

Choose one color at a time. Copy the enclosed module, not the outer color folder.
Updating Shopping Card restores ABD Teal; reapply your alternative color
if desired. Reinstall the main suite's Shopping Card module to restore the default.

These colors change appearance only. Combined balances, payment priority,
capacity checks and native cash display are unchanged. No executable, new items
or save fields are included. Keep personal settings in My Custom QoL Configuration
so replacing the module preserves them.

The default ABD Teal retains the original green design. Bell Gold uses the Bells counter's
gold with a peach-gold card. Hotel Blue uses the hotel ticket counter's blue,
navy edges and a red stripe. Poki Red uses coral red, cream details and a gold
chip. Island pairs the ACNH Switch's turquoise blue with pockets cream.
Island Inverted pairs the ACNH Switch's turquoise blue with a lighter
blue card and cream balance, outlines and backing.
