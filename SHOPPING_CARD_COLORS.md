# Shopping Card color options, revision 3 — QoL Enhancements 0.3.16 / ACNH 3.0.3

Install the normal QoL Enhancements 0.3.16 Core and Shopping Card first.
This download contains optional appearance replacements, not a standalone mod.

1. Fully close the game.
2. Open **Gold** or **Green**, then copy the **QoL Enhancements - Shopping Card**
   folder inside it into your game mods directory. Merge with the existing
   Shopping Card folder and replace its layout file.
3. Keep Core and Shopping Card enabled, then restart the game.

Choose one color at a time. Do not copy the outer Gold/Green folders as separate
mods. Updating the main suite restores its default green appearance; reapply
your chosen color afterward. To restore green now, copy the Green option in
the same way. The Core binary and Shopping Card configuration stay the same.

Gold uses the original Bells UI's gold fill/caption and cream outlines/badge.
The card has the requested light peach-gold #F9C687 face, a darker gold
border and cream details. Revision 3 changes only the card face; the counter
keeps its original Bells gold.
Green reproduces the working 0.3.16 layout exactly. Both retain the same card
shape, detail positions, native 16:9 canvas and balance animations/sounds.

These options contain only the currency layout. They add no items, messages,
save fields or player preferences. Disable/remove Shopping Card and restart
for the usual clean uninstall.

The gold layout passes local structure and resource-size checks. Revision 1
also passed native texture lookup/relocation and texture-byte-order checks;
revisions 2 and 3 change only the foreground card's color pixels. Its final appearance
needs an in-game check. Exported previews illustrate the card and oval; native
text is omitted.
