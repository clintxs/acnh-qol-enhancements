# Shopping Card color options, revision 4 — QoL Enhancements 0.3.16 / ACNH 3.0.3

Install the normal QoL Enhancements 0.3.16 Core and Shopping Card first.
This download contains optional appearance replacements, not a standalone mod.

1. Fully close the game.
2. Open your chosen color folder, then copy **QoL Enhancements - Shopping Card**
   folder inside it into your game mods directory. Merge with the existing
   Shopping Card folder and replace its layout file.
3. Keep Core and Shopping Card enabled, then restart the game.

Choose one color at a time. Do not copy the outer color folders as separate
mods. Updating the main suite restores its default ADB Teal appearance; reapply
your chosen color afterward. To restore teal, copy the ADB Teal option in
the same way. The Core binary and Shopping Card configuration stay the same.

Bell Gold uses the original Bells UI's gold fill/caption and cream outlines/badge.
The card has the requested light peach-gold #F9C687 face, a darker gold
border and cream details. Revision 3 changes only the card face; the counter
keeps its original Bells gold.
Hotel Blue uses the hotel ticket UI's blue counter, lighter blue card, navy
border and red stripe, with cream details and outlines. Poki Red uses the Poki
bag's light coral-red for the card, a deeper warm-red counter and border,
cream details/outlines and a gold chip. Colors are based on the supplied
screenshots. These options still display Bells and spend savings.
ADB Teal reproduces the working 0.3.16 layout exactly. All retain the same card
shape, detail positions, native 16:9 canvas and balance animations/sounds.

Future downloads use the names Bell Gold and ADB Teal. Earlier downloads call
these folders Gold and Green, respectively; the appearance stays the same.

These options contain only the currency layout. They add no items, messages,
save fields or player preferences. Disable/remove Shopping Card and restart
for the usual clean uninstall.

Local checks cover layout structure, original resource preservation, the
resource-size allowance and texture colors/coverage. The new palettes need
an in-game appearance check. Exported previews illustrate the card and oval;
native text is omitted. ADB Teal and the revision 3 Bell Gold artwork are preserved.
